# Distance Calculator

## Description
This project focuses on calculating distance with the requirement of the user to input the coordinates of two points.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input needed
The user is required to input the values of two points which are being represented as x1, y1, x2, y2.

## Sample output
```markdown
Enter x1: 5
Enter y1: 2
Enter x2: 4
Enter y2: 2
The distance is 1.0
```
